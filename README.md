# OFF/SET — Distorted Poster Map

브라우저 안에서 포스터를 개별 요소로 나누고, 흔들림으로 물리적 변형을 만든 뒤 저장하는 웹 앱입니다. 별도 서버나 API 키 없이 실행됩니다.

## 실행

Node.js 24와 npm을 사용합니다. PDF 처리 라이브러리는 Node.js 22.13 이상을 요구하며, 배포 시에는 검증한 Node.js 24를 사용하도록 지정했습니다.

```sh
npm ci --cache /workspace/.cache/npm
npm run dev
```

다른 환경에서는 `--cache` 옵션을 생략해도 됩니다. 개발 서버 기본 포트는 5173입니다.

```sh
npm run build
npm test
npm run test:browser
npm run preview
```

브라우저 통합 검사는 시스템 Chromium(`/usr/bin/chromium`)을 사용합니다. 다른 위치의 브라우저는 `CHROMIUM_PATH`로 지정할 수 있습니다. 통합 검사에서 개발 서버를 별도 포트(4175)로 시작하고 종료하며, PNG/JPG 업로드, 다중 페이지 PDF의 텍스트 분리, 물리 효과, 좌표, 저장 파일, 모바일 화면을 확인합니다.

빌드된 결과물은 `npm run build` 후 `SMOKE_PRODUCTION=1 npm run test:browser`로 같은 기능을 검증합니다.

## Vercel 배포

Vercel 프로젝트에 `yeonjoo-kim/DistortedPosterMap` 저장소의 `main` 브랜치를 연결합니다. 루트 디렉터리는 저장소 루트이며, 프레임워크는 Vite, 빌드 명령은 `npm run build`, 출력 디렉터리는 `dist`입니다. 이 설정은 `vercel.json`에 저장되어 있습니다. API 키나 환경 변수는 필요하지 않습니다. `main` 브랜치에 새 커밋을 올리면 Vercel에서 자동 배포합니다.

## 동작

- PDF, JPG, PNG 업로드(최대 50MB), PDF 페이지 선택
- PDF 원본 텍스트 위치와 배경 대비 픽셀 연결 영역을 활용한 요소 분리
- 복잡한 사진은 격자 조각으로 분리, 분리 수준 선택
- Matter.js 기반 중력, 반발, 충돌 및 삼각 파편 생성
- 수평 스트립 변위 기반 지그재그 효과
- 드래그 속도 및 기기 가속도에 비례한 흔들림, 민감도 조절
- Space / 흔들기 버튼, 일시정지, 원본 보기, 초기화
- 개별 요소 좌표·이동량·회전·변형량과 이동 경로 표시
- PNG / JPG / 이미지 기반 PDF 출력(1×–3×), 좌표·경로·변형 꼭짓점 JSON 저장

## 구현 범위

기기 센서는 브라우저가 `DeviceMotionEvent`를 제공하는 기기와 HTTPS 또는 localhost에서만 작동합니다. 일반 노트북에서 물리적인 흔들림을 브라우저로 감지할 수 없는 경우가 많으므로 마우스/트랙패드, Space 키와 버튼 입력을 함께 제공합니다.

이미지 분리는 컴퓨터 비전의 픽셀 연결 영역을 사용하며 의미 단위 사물 인식이나 OCR 모델은 포함하지 않습니다. 살아 있는 텍스트를 포함한 PDF 및 단색 배경의 그래픽 포스터에서 가장 잘 작동합니다. 복잡한 배경이나 겹친 요소는 하나로 합쳐질 수 있습니다. 분리되지 않은 픽셀은 배경에 남겨 이미지가 사라지지 않도록 합니다. 투명 PNG의 투명 배경은 추정 배경색으로 채웁니다. 긴 변을 최대 1,200px로 분석하므로 2×·3× 출력은 확대 출력이며 원본 벡터 품질 복원을 뜻하지 않습니다. PDF 텍스트는 텍스트 영역별로 분리하고 그 외 벡터는 렌더링한 픽셀을 분석합니다. 회전된 PDF 텍스트나 복잡한 레이아웃은 분리 정확도가 낮을 수 있습니다.

파일은 메모리에서 처리되며 서버에 업로드되지 않습니다. 페이지 새로고침 시 작업은 초기화됩니다. 외부 폰트가 차단되어도 시스템 폰트로 작동합니다.

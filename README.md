# Poster Distorting Map

브라우저에서 PDF·JPG·PNG 포스터를 자동으로 요소로 분리하고, 노트북·카메라의 상대 움직임 강도에 따라 변형하고 연주하는 웹 앱입니다. 별도 서버나 API 키가 필요하지 않습니다.

## 실행과 검증

Node.js 24와 npm을 사용합니다.

```sh
npm ci --cache /workspace/.cache/npm --no-audit --no-fund
npm run dev -- --port 5173
```

다른 환경에서는 `--cache` 옵션을 생략할 수 있습니다. 개발 서버와 배포용 정적 결과물을 검증하는 명령입니다.

```sh
npm test
npm run build
SMOKE_PRODUCTION=1 npm run test:browser
npm run preview
```

브라우저 검사는 시스템 Chromium(`/usr/bin/chromium` 또는 `CHROMIUM_PATH`)을 사용합니다. 자체 서버를 4175 포트에서 시작하고 종료합니다. SVG 디자인과 빈 업로드 화면, 자동 분리, 실제 입력 처리 경로, 화면 전체의 충돌·파편화와 움직이는 UI, 소리 출력, 저장 파일 및 모바일 화면을 검사합니다. 테스트 스크린샷은 `test-results/`에 생성됩니다.

## 화면과 재료

사용자가 제공한 Home.svg, Start.svg, Procss.svg를 시각 참고로 삼았습니다. 로고·About은 첨부 SVG의 배치를 참고하되 글꼴이 전환되도록 실제 텍스트로 표시합니다. 초기 화면은 옅은 노란 배경과 빈 종이, 오른쪽 하단 연두색 조절 박스를 사용합니다. 테이프 스티커는 제거했고 업로드 버튼은 단순한 더하기 아이콘입니다. 포스터를 읽으면 화면 전체와 저장 이미지의 배경을 포스터의 주된 테두리 배경색으로 맞춥니다. 어두운 배경에서는 로고·About과 업로드 아이콘을 밝게 표시합니다.

- 포스터 업로드, 움직임 감지, 연주 소리 켜기/끄기, 움직임 시각화, 다운로드만 조절 박스에 남겼습니다. 개별 요소 목록·선택·삭제·수동 흔들기·물리 슬라이더·모드 선택·원본 비교·초기화·일시정지는 없습니다.
- 로고, About, 조절 박스는 부서지지 않는 물체로 움직입니다. 수직 움직임에서도 화면 중앙으로 향하는 힘을 더해 오른쪽에 머물지 않고 퍼집니다. 메뉴는 화면 안의 별도 위치에 표시하여 물체가 움직여도 선택할 수 있습니다. About은 간단한 소개를 엽니다.
- 카메라는 이전의 광학 흐름 방식으로 영상 전반의 이동을 분석합니다. 강도는 `(속도 − 2) / 48`의 0.75승이며 정지 장면과 추적 신뢰도 0.6 미만은 입력을 억제합니다. 몸·관절 인식 모델과 카메라 시작 안내 팝업은 제거했습니다. 카메라는 사용자가 기존 움직임 감지 메뉴에서 직접 시작합니다.
- UI의 영문·숫자는 첨부한 `MetaAccanthis.ttf`를 기본으로 사용하고, 첫 물리 왜곡이 시작되면 `MetaAccanthisAlternate.ttf`로 바뀝니다. 새 포스터 업로드 시 기본 글꼴로 돌아갑니다. 로고·About·버튼·좌표 숫자·포스터 위 좌표 오버레이에도 적용합니다. 폰트에 없는 한글은 시스템 글꼴로 표시합니다. 업로드된 포스터 자체의 글자는 원본 이미지에 포함된 모양을 유지합니다.
- 포스터와 UI의 이동 충격을 약 2–4배로 늘리고 공기 저항·마찰을 줄였습니다. 최대 이동 속도를 높이고 반발력을 늘렸으며, 새로운 흔들림이 오면 바닥에 쌓인 조각도 위로 튀어 올라 다시 화면을 돌아다닙니다. 입력이 없을 때는 스스로 흔들리는 힘을 만들지 않습니다.
- 움직임을 감지하면 포스터 요소가 중력에 따라 떨어지고 충돌 시 눌렸다 복원되며, 강한 충돌에서는 삼각형 파편으로 나뉩니다. 포스터의 종이 경계를 넘어 브라우저 화면 전체에서 반응합니다. 브라우저 창 바깥이나 운영체제 바탕화면으로 나가지는 않습니다.
- `MATERIAL_MIX`는 지그재그 0.2, 부서짐 0.8입니다. 지그재그 변위의 주입량과 상한을 종전의 20%로 줄이고, 부서짐 가중치로 충돌 속도 임계값과 손상을 계산합니다. 중간 이상의 흔들림에서도 파편화가 발생합니다. 이는 재료 반응 가중치이며 매 프레임 픽셀 수나 조각 수가 정확히 20:80이라는 뜻은 아닙니다.
- 소리는 헤비메탈 기타를 모사한 로컬 합성음입니다. Karplus–Strong 방식의 줄 튕김으로 E 마이너 리프의 근음·5도·옥타브 파워코드를 만들고, 오버샘플링 디스토션 앰프와 캐비닛 필터를 통과시킵니다. 작은 움직임은 낮고 짧은 팜뮤트, 큰 움직임은 빠르고 밝고 긴 파워코드로 반응하고 충돌에서도 다시 피킹합니다. 녹음된 기타 샘플은 사용하지 않습니다. 최초 사용자 동작으로 Web Audio를 시작하고 스피커 버튼으로 음소거합니다.
- 조절 박스의 Position X/Y 및 Offset X/Y는 포스터 요소들의 원본 면적으로 가중한 중심 위치와 이동량(px)입니다. 파편으로 나뉘어도 면적 가중치의 합을 보존합니다. 읽기 영역을 누르면 포스터 위의 개별 좌표·이동 경로가 켜집니다.

## 노트북·카메라 움직임 감지

카메라 입력은 몸·관절 인식이 아닌 이전의 광학 흐름 방식입니다. 영상 전반의 이동으로 노트북과 배경 사이의 상대 움직임을 추정하며, 실제 가속도 실측과 다릅니다. 사람이나 배경 자체가 크게 움직여도 반응할 수 있습니다. 충분한 조명과 무늬가 있는 정지한 배경이 필요합니다.

1. 포스터를 업로드합니다. 카메라 안내 팝업이나 자동 카메라 시작은 없습니다.
2. **움직임 감지 → 카메라로 움직임 감지**를 선택하고 브라우저·운영체제의 카메라 권한을 허용합니다.
3. 정지한 배경이 영상에 넓게 보이도록 하고 노트북을 조금 움직여 **카메라 추정** 강도와 포스터가 반응하는지 확인합니다.
4. 스피커 아이콘으로 연주 소리를 켜고 끕니다.
5. **움직임 감지 → 움직임 감지 중지**로 카메라를 해제합니다.

영상은 기기 메모리 안에서만 분석하며 저장·전송하지 않습니다. 마이크는 요청하지 않습니다. 감지 중지·입력 전환·탭 이탈·컴포넌트 해제 시 카메라 트랙을 중지합니다. 인식 모델·WASM·추가 모델 준비 스크립트는 사용하지 않습니다.

가속도 센서 확인도 선택할 수 있습니다. `DeviceMotionEvent`는 실제 가속도 데이터를 두 번 이상 받아야 연결로 표시하고 무응답·끊김·권한 거부를 구분합니다. **2020년형 13인치 M1 MacBook Pro에서 브라우저가 가속도를 제공한다고 보장할 수 없습니다.**

테스트는 정지/이동/일부 전경 변화의 광학 흐름과 입력 강도 응답을 검사합니다. 브라우저에서는 합성 가속도 이벤트와 캔버스 기반 가짜 카메라 영상을 실제 입력 처리 코드에 연결하여 물리·기타 소리·글꼴 전환·저장을 검증합니다. 실제 사용자 M1 기기의 하드웨어 시험 결과는 아닙니다.

## 파일과 저장

입력은 PDF·JPG·PNG(최대 50MB)입니다. PDF는 첫 페이지를 사용하며, 텍스트 영역을 분리한 뒤 나머지를 픽셀 분석합니다. JPG·PNG는 픽셀 연결 영역을 분석합니다. 의미 단위 AI 분리나 OCR 모델은 포함하지 않습니다. 단색 배경의 그래픽 포스터와 텍스트 PDF에서 잘 작동하며, 복잡하거나 겹친 요소는 합쳐질 수 있습니다. 복잡한 사진은 타일 분리로 대체할 수 있습니다. 분리되지 않은 픽셀은 원래 종이의 배경에 남습니다.

Download에서 PNG·JPG·이미지 기반 PDF 및 좌표·경로 JSON을 저장합니다. 이미지에는 종이 밖으로 퍼진 조각을 포함한 현재 화면 크기의 포스터 영역을 담으며, UI는 포함하지 않습니다. 시각화가 켜졌다면 좌표·경로도 포함합니다. JSON에는 포스터 좌표계 기준 화면 경계, 입력, 개별 요소의 원래/현재 위치·변형 꼭짓점·경로 및 부서지지 않는 UI 물체의 위치가 포함됩니다. 화면 크기를 바꾸면 물리 경계를 갱신하고 UI 물체를 디자인상의 위치에 다시 배치합니다.

긴 변을 최대 1,200px로 분석하고 현재 화면 영역을 포스터 좌표계의 2배로 출력합니다. 확대 출력은 원본 벡터 품질 복원을 뜻하지 않습니다. PDF 출력도 래스터 이미지입니다. 파일은 서버에 업로드하지 않으며 새로고침 시 작업이 초기화됩니다.
